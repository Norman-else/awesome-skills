# Awesome Skills

Shared skill pack for Codex and Claude Code.

This repository is the canonical source for Norman's reusable skills. Codex and
Claude Code should install from this repository instead of maintaining separate
copies under `~/.codex/skills` and `~/.claude/skills`.

## Plugins and skills

This marketplace ships **two** plugins. The core pack is for everyone; the
Vault pack is optional and only useful if you run Vault, so it is **not**
installed with the core pack — install it separately.

`awesome-skills` (core):

- `ci-deploy`
- `clean-my-mac`
- `remote-github-pr`

`vault-skills` (optional — requires the Vault MCP integration):

- `vault-share`
- `vault-web-ui`

## Repository layout

```text
.agents/plugins/marketplace.json       # Codex marketplace metadata (both plugins)
.claude-plugin/marketplace.json        # Claude Code marketplace metadata (both plugins)
plugins/awesome-skills/                # core pack
  .codex-plugin/plugin.json            # Codex plugin manifest
  .claude-plugin/plugin.json           # Claude Code plugin manifest
  skills/                              # ci-deploy, clean-my-mac, remote-github-pr
plugins/vault-skills/                  # optional Vault pack
  .codex-plugin/plugin.json
  .claude-plugin/plugin.json
  skills/                              # vault-share, vault-web-ui
```

## Install in Codex

Use the repo-local Codex marketplace:

```text
/plugin marketplace add /path/to/awesome-skills/.agents/plugins/marketplace.json
/plugin install awesome-skills
# optional, only if you use Vault:
/plugin install vault-skills
```

From a checked-out copy of this repository, that path is:

```bash
pwd
# then use: /plugin marketplace add <that path>/.agents/plugins/marketplace.json
```

## Install in Claude Code

Add this repository as a Claude Code plugin marketplace, then install the plugin:

```text
/plugin marketplace add https://github.com/Norman-else/awesome-skills
/plugin install awesome-skills
# optional, only if you use Vault:
/plugin install vault-skills
```

For local development, add the local checkout instead:

```text
/plugin marketplace add /path/to/awesome-skills
/plugin install awesome-skills
```

## Development rule

Edit skills only under the owning plugin's `skills/` directory — core skills in
`plugins/awesome-skills/skills`, Vault skills in `plugins/vault-skills/skills`.
Treat `~/.codex/skills` and `~/.claude/skills` as install targets generated by
the clients.

**Always bump the version when you change a skill** — even for content-only
`SKILL.md` edits. Clients (Claude Code / Codex) cache the plugin by version, so
an unchanged version means `/reload-plugins` never re-fetches and your edit
never reaches users. For the **core** pack, bump the same `version` in all three
manifests: the `awesome-skills` entry in `.claude-plugin/marketplace.json`,
`plugins/awesome-skills/.claude-plugin/plugin.json`, and
`plugins/awesome-skills/.codex-plugin/plugin.json`. `scripts/check.sh` enforces
this for the core pack: it fails if the watched paths changed but the version
still matches `HEAD`, or if those three manifests disagree. For the **vault-skills**
pack, keep its `version` in sync across its `marketplace.json` entry and its two
`plugin.json` manifests the same way (not yet covered by `check.sh`).

Only add skills that are owned by this repository. Do not vendor bundled,
official, marketplace, or third-party skills unless they are intentionally
forked and relicensed here.

Before publishing changes:

```bash
./scripts/check.sh
```
