# Awesome Skills

Shared skill pack for Codex and Claude Code.

This repository is the canonical source for Norman's reusable skills. Codex and
Claude Code should install from this repository instead of maintaining separate
copies under `~/.codex/skills` and `~/.claude/skills`.

## Included skills

- `ci-deploy`
- `clean-my-mac`
- `remote-github-pr`
- `vault-share`
- `vault-web-ui`

## Repository layout

```text
.agents/plugins/marketplace.json       # Codex marketplace metadata
.claude-plugin/marketplace.json        # Claude Code marketplace metadata
plugins/awesome-skills/
  .codex-plugin/plugin.json            # Codex plugin manifest
  .claude-plugin/plugin.json           # Claude Code plugin manifest
  skills/                              # Canonical skill source
```

## Install in Codex

Use the repo-local Codex marketplace:

```text
/plugin marketplace add /path/to/awesome-skills/.agents/plugins/marketplace.json
/plugin install awesome-skills
```

From a checked-out copy of this repository, that path is:

```bash
pwd
# then use: /plugin marketplace add <that path>/.agents/plugins/marketplace.json
```

## Install in Claude Code

Add this repository as a Claude Code plugin marketplace, then install the plugin:

```text
/plugin marketplace add https://github.com/Norman-else/awesome-skills
/plugin install awesome-skills
```

For local development, add the local checkout instead:

```text
/plugin marketplace add /path/to/awesome-skills
/plugin install awesome-skills
```

## Development rule

Edit skills only in `plugins/awesome-skills/skills`. Treat `~/.codex/skills` and
`~/.claude/skills` as install targets generated by the clients.

**Always bump the version when you change a skill** — even for content-only
`SKILL.md` edits. Clients (Claude Code / Codex) cache the plugin by version, so
an unchanged version means `/reload-plugins` never re-fetches and your edit
never reaches users. Bump the same `version` in all three manifests:
`.claude-plugin/marketplace.json`, `plugins/awesome-skills/.claude-plugin/plugin.json`,
and `plugins/awesome-skills/.codex-plugin/plugin.json`. `scripts/check.sh`
enforces this: it fails if the watched paths changed but the version still
matches `HEAD`, or if the three manifests disagree.

Only add skills that are owned by this repository. Do not vendor bundled,
official, marketplace, or third-party skills unless they are intentionally
forked and relicensed here.

Before publishing changes:

```bash
./scripts/check.sh
```
